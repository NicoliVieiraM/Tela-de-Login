# 🔐 Tela de Login Responsiva

Uma tela de login moderna, responsiva e interativa, construída para complementar o formulário de cadastro. Desenvolvida com HTML, CSS e JavaScript puro (Vanilla).

## ✨ Funcionalidades

- **Design Responsivo:** Adapta-se perfeitamente a diferentes tamanhos de tela (desktop e mobile).
- **Toggle de Senha:** Ícone interativo para mostrar/esconder a senha digitada.
- **Validação Básica:** Verifica se os campos estão preenchidos antes de permitir o login.
- **Integração Visual:** Compartilha o mesmo padrão de cores (`#ee96db`, `#faf0f5`) e fontes do sistema de cadastro.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Função |
|---|---|
| **HTML5** | Estruturação semântica da página |
| **CSS3** | Estilização, layout (Flexbox/Grid) e responsividade |
| **JavaScript** | Interatividade (mostrar senha, alertas) |
| **Font Awesome 6** | Ícones dos inputs e botões |
| **Google Fonts** | Tipografia principal (DM Sans) |

## 📁 Estrutura do Projeto

## 🚀 Como testar localmente

```bash

```

3. Dê um clique duplo no arquivo `index.html` para abrir no seu navegador, ou utilize a extensão **Live Server** no VS Code.
